# Academic Performance Tracker for UiTM

A program created to track course performance in a Computer Science diploma program.

## Features

1. **Track Attendance**
2. **Final Assessment Eligibility**
3. **Calculates:**
   - Minimum Passing Marks & Carry Marks
   - Obtained Marks & Carry Marks
   - Maximum Carry Mark Potential
   - Grade & Grade Point
   - Course Status
4. **Arrow Keys and Vim Navigation**

---

## Why This Program Was Created

This program was created to track this complicated passing requirements

### Peraturan Akademik Diploma dan Sarjana Muda UiTM (Pindaan 2021) Bilangan 1

#### 2.14 Kehadiran Pelajar
> **2.14.2** Pelajar yang tidak mencapai kehadiran 80% dari jumlah jam temu untuk setiap kursus tanpa mendapat kebenaran bertulis dari Kolej Pengajian/Fakulti/Pusat Akademik/UiTM Cawangan tidak dibenarkan menduduki peperiksaan akhir kursus. Bagi kursus yang tiada peperiksaan akhir, kerja kursus tidak diberi penilaian.

### Pindaan Syarat Lulus Kursus Dalam Peraturan Akademik Diploma dan Sarjana Muda Pindaan 2021 (Bilangan 1)

| Komponen Penilaian | Tahap Peratus Lulus Kursus Sedia Ada | Pindaan Tahap Minimum Peratus Lulus Kursus |
| :--- | :--- | :--- |
| **Penilaian Keseluruhan** | 50% | 50% |
| **Penilaian Berterusan** | Tiada | 50% |
| **Penilaian Akhir / Pentaksiran Akhir** | Tiada | 20% |
| **Peperiksaan Akhir** | Tiada | 20% |

#### 2.36 Syarat Lulus Kursus
Pelajar memperoleh status **Lulus (LU)** sesuatu kursus apabila:
> **2.36.1** Telah mencapai tahap minimum peratus lulus kedua-dua komponen iaitu penilaian berterusan dan peperiksaan akhir atau penilaian akhir / pentaksiran akhir yang telah ditetapkan; **DAN**
> 
> **2.36.2** Telah mencapai tahap peratus lulus (minimum Gred C) secara keseluruhan penilaian.

#### 2.37 Kegagalan Komponen
Pelajar yang gagal kursus disebabkan gagal salah satu komponen iaitu penilaian berterusan dan peperiksaan akhir atau penilaian akhir / pentaksiran akhir:
> **2.37.1** Tidak dibenarkan menduduki penilaian atau peperiksaan semula pada semester yang sama setelah keputusan peperiksaan diumumkan secara rasmi; **DAN**

> **2.37.2** Perlu mendaftar dan mengulang kursus yang gagal pada semester seterusnya.

| Status Penilaian Berterusan (CA) | Status Pentaksiran / Peperiksaan Akhir (FA) | Nilai Gred Diperolehi | Kod Status Kursus |
| :--- | :--- | :--- | :--- |
| Lulus (LU) | Gagal (GA) | 1.67 | GF |
| Gagal (GA) | Lulus (LU) | 1.67 | GC |
